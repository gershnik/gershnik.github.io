Passwords

When you create or edit a connection, you can choose to save the username and password used to sign in to the remote machine.

If you do not save them, you will be prompted when you connect. The connection prompt also lets you save the credentials for future use.

How passwords are stored

Saved passwords are stored securely in your Mac’s Keychain. They are never written to the application’s own settings or data files.

Each saved password belongs to a particular connection and is associated with that connection’s remote host and port. This allows you to create multiple connections to the same remote machine with different credentials without one connection overwriting another.

These Keychain entries are also separate from passwords managed by the macOS Passwords app. Saving or changing a password here does not alter passwords stored there, and vice versa.

Passwords on multiple Macs

Saved passwords are local to the Mac on which they were created. They are not synchronized through iCloud.

If you use the application on another Mac, passwords saved on one machine will not appear on the other.

Removing saved passwords

When you delete a connection, any password stored specifically for that connection is removed from the Keychain as well.

You therefore do not need to clean up old application passwords manually after removing connections.

If a saved password is not found

Very rarely, macOS may temporarily prevent an application from accessing the Keychain correctly. If this happens, you may be prompted for a password even though one is already saved for the connection.

Quitting and reopening the application will usually restore Keychain access.
