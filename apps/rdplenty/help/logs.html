Application logs

RDPlenty keeps a local log that can be useful when diagnosing connection problems, unexpected behavior, or other issues.

The log files are stored under:

~/Library/Containers/com.gershnik.RDPlenty/Data/Library/Logs/com.gershnik.RDPlenty/

The current log file is:

rdplenty.log

Because that location is not especially convenient to navigate to manually, the application settings include a button that opens the log folder directly in Finder.

Log settings

The application settings also let you control how logging is managed:

  • the minimum log level

  • the maximum size of each log file

  • how many rotated log files are retained

For everyday use, Warning or Info is usually sufficient.

Use Debug or Trace when investigating a problem. These levels record much more detail and can produce large log files, especially during longer sessions.

Using logs for troubleshooting

Logs can be useful when diagnosing a problem yourself or when reporting a bug or other issue.

Before sharing a log, review it first. Depending on what the application was doing, log files may contain private or sensitive information such as host names, account names, network addresses, connection details, or other diagnostic data. Share only what is necessary for the problem being investigated.
