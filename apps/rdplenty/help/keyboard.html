Keyboard

Keyboard input is translated so that your Mac keyboard behaves naturally in the remote Windows session. Most keys and key combinations are sent directly to Windows.

Command keys

By default, the left ⌘ key acts as Ctrl in the remote session. This makes common Windows shortcuts work with the same muscle memory you use on your Mac: ⌘C, ⌘V, ⌘S, and so on.

The right ⌘ key acts as the Windows key. This lets you use Windows shortcuts that require the Windows key while keeping the left ⌘ key available for everyday shortcuts.

If you prefer the left ⌘ key to act as the Windows key rather than being mapped to Ctrl, you can disable this Command-key mapping in the connection settings, on the Features tab.

Special keys

Some Windows keys and key combinations cannot be generated normally from a Mac keyboard, or are intercepted by macOS before they reach the remote session. You can send these through Connection → Special Keys.

The menu provides:

  • Win + Tab

  • Win + Shift + Tab

  • Win + Ctrl + Q

  • Win + Alt + Esc

  • Ctrl + ←

  • Ctrl + →

  • Ctrl + ↑

  • Ctrl + ↓

  • Break

  • Print Screen

  • Insert

  • Scroll Lock

For Break, Print Screen, Insert, and Scroll Lock, you can also combine the key with Ctrl, Alt, or Shift. Hold the desired modifier key or keys while selecting the key from the menu.

Caps Lock

The Caps Lock state is normally synchronized between your Mac and the remote Windows machine.

In unusual cases, the two sides can become out of sync. If that happens, press Caps Lock once. This will normally bring the two states back into sync.
