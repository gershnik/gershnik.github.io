Clipboard

Clipboard sharing is enabled by default and works in both directions: you can copy and paste between your Mac and the remote machine. You can disable it in the connection settings, on the Features tab.

Supported content

The clipboard can transfer three kinds of content:

  • Plain text — always supported, including accented characters, non-Latin scripts, and emoji.

  • Formatted text — bold, italics, fonts, colors, tables, lists, and other formatting can be preserved. How faithfully the formatting is reproduced depends on the receiving application and on whether the required fonts are installed there.

  • Images — screenshots, photographs, and image selections copied from an application are transferred as pictures, with transparency preserved.

Files and folders are deliberately not supported. The RDP clipboard mechanism cannot transfer files reliably. To move files between the two machines, use a file share such as SMB or scp.

Other clipboard formats — such as sounds or data understood only by a particular application — are ignored. Copying such content does not produce an error or warning; there is simply nothing to paste on the other side.

Choosing a format

Most applications put the same clipboard content into several formats at once. For example, copying a spreadsheet selection may put plain text, formatted text, and HTML on the clipboard.

The application you paste into chooses the format it prefers. This is why the same clipboard contents might appear as a formatted table in a word processor but as plain text in a text editor.

You do not normally need to choose the format yourself. If the result is less formatted than expected, try pasting into another application or use Paste Special, if the receiving application provides it.

HTML

When formatted content is transferred as HTML, only the copied fragment is transferred, not the entire page or document it came from. Styles that exist only in the surrounding document may therefore be lost, making the pasted result look plainer than the original.

If the source application also provides RTF, that will often preserve the appearance better. Most word processors provide RTF, and the receiving application will normally choose it automatically when appropriate.

Line endings

Text line endings are converted automatically when crossing between macOS and Windows.

Mac and Unix programs normally use a single LF character (\n) to end a line, while Windows uses CR+LF (\r\n). Text copied to the remote Windows machine is converted to CR+LF; text copied back to the Mac is converted back to LF.

This means pasted text uses the native line endings expected by applications on each side, without stray ^M characters or lines running together.

Images

Images are converted between Mac and Windows image formats as necessary. Transparency is preserved, and embedded color profiles are honored where the image format supports them, so screenshots and photographs should retain their original colors.

Image conversion is lossless, but large images can take noticeable time and memory to process. A full multi-monitor screenshot, for example, may be quite large.

How clipboard transfer works

Clipboard data is transferred on demand. When you copy something, the other machine is initially told only which clipboard formats are available. The actual data is not transferred until an application on the other side requests it, normally when you paste. Some applications may request it earlier as soon as they notice that the clipboard has changed.

This means that large clipboard contents are not sent across the connection unless something actually requests them.

There are two important consequences:

  • Large or slow transfers can time out. If fetching an item takes more than a few seconds, the transfer is abandoned and the paste produces nothing. This is most likely on a slow or congested connection. Copying and pasting again will usually work.

  • The source must remain connected. Because the actual data is fetched only when requested, clipboard contents copied on one machine must still be available when the other machine requests them. For example, if you copy something on the remote machine and then disconnect before pasting it on the Mac, the clipboard contents can no longer be fetched and the paste produces nothing.

Limitations

  • Files and folders cannot be copied through the clipboard. Use SMB, scp, or another file-transfer method instead.

  • Very large clipboard items may fail. There is no fixed size limit, but transfers that take more than a few seconds are abandoned. For genuinely large data, use a file share or scp.

  • Rich formatting is best-effort. Formatting that depends on fonts, styles, or embedded objects unavailable on the receiving machine may be approximated or lost.

  • Unsupported clipboard formats are ignored. If the copied content is not plain text, formatted text, or an image, nothing will appear when you try to paste it.
